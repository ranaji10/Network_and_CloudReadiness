# Copperfield Marine Insurance - Licences and Cost Baseline (SYNTHETIC)

- Licence inventory: Microsoft enterprise agreement (renewal date next March, software assurance, BYOL eligible),
  Oracle support contract, VMware subscription.
- Cost baseline: TCO model with capex (hardware depreciation over 5 years) and opex (annual cost of licences,
  power, colocation); monthly cost reports per application.
- Cloud cost governance: FinOps owner nominated; tagging policy with labels per cost center; budget alert per project.
- Operations: Terraform for the landing zone, Ansible for servers, a CI/CD pipeline on Azure DevOps, Datadog monitoring,
  runbook per application.
- Skills: training plan with cloud certification targets; a cloud centre of excellence (CCoE) starts next quarter.
- Compliance: the insurance regulator's outsourcing rules, GDPR and ISO 27001; landing zone to follow the security
  foundations blueprint with organization policy guardrails and Cloud KMS CMEK; Security Command Center for posture.
