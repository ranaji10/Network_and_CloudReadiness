# Rustbucket Logistics - IT Overview (SYNTHETIC)

- A firewall appliance was purchased for head office in 2019 and a VPN is used by two remote staff.
- Identity: on-premises Active Directory; no single sign-on for SaaS tools.
- Inventory: 12 physical servers (Windows Server 2016, Hyper-V); VM list kept in a spreadsheet with CPU and RAM.
- Databases: SQL Server 2016 for the ERP; MySQL for the website.
- Security logs: Windows event logs only, no central logging and no SIEM.
- Incident response: no written plan.
- The chatbot uses OpenAI through a small Python service; there is no AI policy.
