# One tracker file per epic

Status: accepted
Date: 2026-10-23

## Context
Several people and several agents will work in parallel. A single tracker file would be a constant
merge conflict; an external tracker would not be available inside an agent's sandbox.

## Decision
Stories live in `docs/planning/tracker/<EPIC>.yaml`, one file per epic. `TRACKER.md` is generated by
`scripts/render_tracker.py` and checked in CI with `--check`. Claiming a story is a small commit
that sets `owner` and `status`.

## Consequences
- Parallel work touches different files; conflicts happen only within one epic.
- The plan travels with every clone.
- People who want GitHub Issues get an optional one-way sync (DOC-06).
